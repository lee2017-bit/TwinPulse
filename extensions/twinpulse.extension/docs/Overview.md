# TwinPulse Playground 0.1.0 (M2-A Copilot UI revision)

This Extension presents a prompt-first, Copilot-inspired workflow with persistent provider Settings, a local reference-image picker/preview, and a modern multimodal Responses adapter. It validates strict structured scene drafts before applying them under `/World/TwinPulse`, places one procedural differential-drive AGV, and provides Build, Focus, Run, Pause, and Reset controls.

Natural-language and image input, structured generation, and generated-bundle scene application are implemented. No API key is bundled and a paid real-provider E2E has not yet been run. ROS2, Isaac Lab, cloud execution, and physical AGV control remain disconnected.
