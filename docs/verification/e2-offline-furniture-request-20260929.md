# E2d 제한된 오프라인 가구 요청 — 2026-09-29

**제한된 로컬 경로 PASS, E2 전체 PARTIAL.** 기존 가구 편집 패널에 짧은 한국어/영어 요청 입력을 추가했다. 정해진 7종 가구의 단일 `추가`/`이동` 의도만 로컬 규칙으로 제안하고, 기존 E1/E2c 수치 양식을 채운다. 모델 호출·사진 판독·외부 자료 검색·자동 미리보기·자동 저장은 없다. 모호하거나 지원하지 않는 요청은 설명과 함께 멈춘다.

## 사용자 경계

- `소파 추가`: 종류만 선택하고 X/Y는 비워 둔다. 사용자가 위치를 입력하기 전 미리보기는 잠겨 있다. `의자 추가 X=0.9 Y=-1.4`처럼 두 좌표를 적으면 양식에 채운다.
- `침대 이동`: 저장 장면의 해당 종류가 하나면 대상을 지정한다. 여러 개면 선택 요청, `선택한 침대`에 선택이 없으면 선택 요청, 없으면 추가 여부 확인을 요구한다. 기존 위치와 변함없는 변경의 미리보기는 잠근다.
- 한 요청에 여러 종류·서로 다른 동작, 삭제/제거, 위치 X/Y 중 하나만 있는 추가 등은 자동 추측하지 않는다. 짧은 설명에서 로컬 프리셋과 저장 장면만 근거로 사용했음을 알린다. 사진이나 한국형 아파트 자료를 실제로 읽었다고 말하지 않는다.
- 해석은 편집 양식 제안일 뿐이다. 변경은 서버의 기존 `preview` 검증→명시 `apply`→장면 재승인→Build를 거쳐야 한다. 원본·과거 이력·실물 실행 잠금은 유지된다.
