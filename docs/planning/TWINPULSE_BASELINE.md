# SIM-alpha source baseline

This is a release preparation copy, not a separate product or replacement for private developer memory. Target version0.1.0-alpha.1; installation/publication claims require actual acceptance and reviewed exact files.

Contracts: immutable input/revision; bounded allowlisted plans; locally authoritative geometry/support/tool compilation; authenticated engine/lease/receipt; no automatic motion from generation/restart/text; late-result/project fences; explicit edit/Undo/checkpoint versus saved scene; declared same-epoch manual updates.

Useful alpha scope is an editable approximate twin with unknowns. Small samples are not a general model benchmark. Coarse proxies and photo-relative refinement failures remain documented. Data loss, wrong-candidate preview and current-render failure are host defects, not quality excuses.

Assets include reviewed ROBOTIS USD/notices, not Isaac runtime/importer/model weights. Only owned source is Apache-2.0. Private photos/projects/raw/reports are excluded; changing private repository visibility needs separate history/privacy review and authority.

Next: finish ordinary-user acceptance, publish honest limits, then improve semantic furniture/placement and recovery with reproducible feedback. Physical LiDAR/Cloud/video reconstruction are separate future work.
